About Library of Psi V1

Every page has exactly 3200 characters from abcdefghijklmnopqrstuvwxyz ,.. The page is interpreted as a base-29 number and divided into the hexagon, wall, shelf, volume, and page coordinates above. The calculation is reversible: the complete location always opens the same page, after closing this file or sharing it with someone who uses this exact V1 archive.

The hexagon identifier is necessarily long for a complete archive. The reader header displays an abbreviated version so it remains inside its frame; the full identifier is preserved in the Hexagon field and in copied locations. Do not change the V1 alphabet, page length, coordinate ranges, or calculation if old locations must continue to work.
